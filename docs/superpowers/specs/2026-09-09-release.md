# Initial release scope

Prepare the existing Cailendar Raycast extension for a Store submission and put
the source in `git@github.com:RadnoK/raycast-acal.git`. Rename the local project
folder to `raycast-acal` as the final filesystem operation.

- Retain the existing extension identifier and OAuth storage so current users
  keep their Fireflies session.
- US English interface, actionable errors, and setup documentation. Natural
  language meeting requests may still be written in Polish or English.
- Raycast 2 on macOS Tahoe (26) or later and Apple Silicon. Build native code
  from source through Raycast's supported Swift integration, without a
  committed binary. The helper may compile both architectures, but Raycast 1
  compatibility is not claimed.
- Raycast AI and Fireflies OAuth; no user-supplied API tokens.
- Read local calendar history and only the selected Fireflies transcript.
- Show a proposal before handing off to the Google Calendar extension's editable
  form. Only the user's final confirmation creates an event or sends invitations.
- MIT license, locked dependencies, CI, release notes, installation instructions,
  privacy disclosures, and a reproducible distribution build.
- Validate the real Raycast command and Store metadata. Record any untested
  external behavior explicitly. Do not submit to the Store or change repository
  visibility as part of preparing this release.

Acceptance follows Raycast's Store preparation guide and the official
`raycast/extensions-swift-tools` integration.
